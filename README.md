# Saddleback Leather: Visual Refresh Concept

A standalone design presentation, not the live Shopify store.

- `index.html`: desktop and mobile mockup presentation
- `concept.html`: responsive homepage concept
- `mockup.png`: static image fallback

## Publish
In Settings > Pages, select Deploy from a branch, then main and / (root), and Save.

Expected website address after deployment: https://bradleyparnell.github.io/saddleback/

No customer data, store credentials, tracking scripts, or Shopify changes are included.
